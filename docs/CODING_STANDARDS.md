# CODING_STANDARDS.md

## General

-   Read PRD.md before implementing any feature.
-   Do not assume requirements.
-   Ask for clarification if requirements conflict.

## Stack

-   Next.js (App Router)
-   TypeScript
-   Tailwind CSS
-   shadcn/ui
-   Framer Motion
-   Prisma
-   PostgreSQL
-   Cloudinary

## Architecture

-   Modular
-   SOLID principles
-   Feature-based organization
-   Strict typing
-   Reusable components

## Naming

-   Components: PascalCase
-   Hooks: useXxx
-   Utilities: camelCase
-   Routes: kebab-case

## Quality

-   ESLint + Prettier
-   Accessible components
-   No duplicated logic
-   Validation with Zod
-   Forms with React Hook Form

## Git

-   Small, focused commits
-   One feature per branch when practical

## Testing

-   Build features incrementally.
-   Verify responsiveness before marking complete.
