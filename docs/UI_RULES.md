# UI_RULES.md

## Design Philosophy

-   Mobile-first. Design for smartphones before desktop.
-   Premium, modern, editorial feel inspired by Phenomenon Studio (do
    not copy layouts).
-   Product photography is the hero of the UI.
-   Clean layouts with generous whitespace.
-   8px spacing system.

## Visual Style

-   Rounded corners (14--24px depending on component)
-   Soft shadows
-   Subtle glass effects where appropriate
-   Smooth micro-interactions (200--350ms)
-   Large typography with clear hierarchy

## Colors

-   Primary: Charcoal Black
-   Secondary: White
-   Accent: Electric Blue
-   Success: Emerald
-   Warning: Amber
-   Error: Crimson

## Navigation

-   Sticky bottom navigation on mobile
-   Hamburger for secondary navigation
-   Floating search
-   Thumb-friendly interactions

## Components

-   Reusable buttons
-   Product cards
-   Brand cards
-   Showroom cards
-   Offer banners
-   Skeleton loaders
-   Empty states

## Product Page

-   Swipe gallery
-   Color-specific image switching
-   Smart Store Finder card
-   Call Store and Get Directions as primary CTAs

## Performance

-   Lazy load images
-   Responsive images
-   No layout shifts
